# AutoLoc

## Acteurs

- Client
- Agent d'agence
- Responsable d'agence
- Administrateur

## Cas d'utilisation

### Client
- Consulter les véhicules
- Rechercher une voiture
- Réserver une voiture

### Agent d'agence
- Gérer les réservations
- Gérer les clients

### Responsable d'agence
- Gérer l'agence
- Consulter les statistiques

### Administrateur
- Gérer les utilisateurs
- Gérer les agences
